# VenueHub - Marriage Hall Booking and Management System

## About the Project

VenueHub is a web-based Marriage Hall Booking and Management System developed using PHP and MySQL. The system allows users to view available marriage halls, make bookings, and check their booking status. Administrators can manage marriage halls, bookings, users, and payment-related information.

## Technologies Used

- PHP
- MySQL
- HTML5
- CSS3
- JavaScript
- Bootstrap
- XAMPP

## Main Features

### User Side
- User registration and login
- View available marriage halls
- View hall details
- Make a booking
- View booking history
- Check booking approval status
- Payment option for approved bookings

### Admin Side
- Admin login
- Manage users
- Manage marriage halls
- Manage hall sections/lines
- View and manage bookings
- Approve or reject bookings
- Manage payment information
- View booking details

## Booking Process

1. User creates an account and logs in.
2. User views available marriage halls.
3. User submits a booking request.
4. Admin reviews the booking.
5. After approval, the booking becomes active.
6. User can proceed to payment.

## Database

The project uses MySQL as its database.

The SQL database file is included in the `database` folder.

## How to Run the Project

1. Install XAMPP.
2. Start Apache and MySQL.
3. Copy the project folder into:

   `C:\xampp\htdocs\`

4. Create a database in phpMyAdmin.
5. Import the provided SQL file.
6. Configure the database connection in the project's configuration file.
7. Open the project in your browser:

   `http://localhost/vh/`
